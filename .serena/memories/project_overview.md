# Enki project overview
- Bun/Turbo monorepo with workspaces: backend, frontend, packages/*.
- Backend: Elysia/Bun TypeScript app in backend/src, build uses `bun build --compile --target=bun-linux-amd64 --outfile=dist/server ./src/main.ts`.
- Frontend: Vinext/Vite/TanStack Router React app in frontend/src, SDK generated by Kubb into frontend/src/lib/api/generated.
- SQL package: packages/sql uses Prisma Next (`@prisma-next/*`) with generated contract artifacts under packages/sql/src/prisma/contract.* and migrations under packages/sql/src/migrations.
- Repo uses Biome, TypeScript, Turbo, Lefthook. Package manager: Bun 1.3.x.
- Important local rule: do not mutate remote services; local edits/builds/tests/commits are fine. Commit completed tasks with Codex author and local committer when changes are made.
